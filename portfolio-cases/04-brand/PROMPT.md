# 시안 생성 프롬프트 — 04 brand (브랜드/포트폴리오형)

> 루트 `PROMPT.md`의 `## 04-brand / PROMPT.md` 섹션을 그대로 복사한 것.
> 변수([대괄호] / [샘플 콘텐츠])는 고객 정보로 교체해서 사용.

---

[랜딩페이지 유형]: 브랜드/포트폴리오형

[목적]: 개인/스튜디오 브랜드 인지도 + 작품 노출 + 의뢰 유도

[전환 핵심]
- 작품이 주인공, 디자인은 보조
- "이 사람한테 의뢰하고 싶다"는 감정적 결정 유도
- 정보 밀도는 낮게, 시각 위계는 강하게

[참고 레퍼런스]
첨부 이미지의 갤러리 레이아웃, 여백 활용, 타이포 위계 응용.

[페이지 구조 - 순서대로]

### 1. 히어로 섹션 (브랜드 첫인상)

**세부 요소**:
- 풀스크린 또는 와이드 비주얼 (대표 작품 placeholder)
- 큰 브랜드명/이름 (타이포 강조)
- 짧은 슬로건 (한 줄, 본인 정체성)
- 작은 라벨: 분야 ("Graphic Designer", "Photographer")
- 부드러운 스크롤 유도 (아래 화살표 또는 "Explore Work")

### 2. 자기소개 섹션 (이 사람은 누구인가)

**구성**:
- 좌측 텍스트 (3~4문장):
  - 1문장: 직업 정체성 + 경력
  - 2문장: 어떤 작업을 좋아하는지 / 철학
  - 3문장: 함께 일한 클라이언트 또는 성과
- 우측 프로필 이미지 (placeholder)
- 또는 위아래 배치도 가능

### 3. 작품 갤러리 (메인 섹션, 가장 큰 비중)

**구성 옵션 A — 그리드**:
- 3열 또는 메이슨리 그리드
- 작품 이미지 placeholder 6~9개
- 호버 효과 (CSS hover):
  - 작품 제목 + 카테고리 + "View Project →" 표시
  - 또는 살짝 줌인/그림자 강화
- 모바일 1~2열

**구성 옵션 B — 케이스 스터디**:
- 작품 3~4개 풀폭 카드:
  - 큰 이미지 + 프로젝트명
  - 클라이언트 + 작업 내용
  - "View Case Study →"

(레퍼런스 이미지에 맞게 선택)

### 4. 분야/서비스 섹션

**구성**:
- 작은 라벨: "What I do" 또는 "Services"
- 3~4개 서비스:
  - 아이콘 또는 일러스트
  - 서비스명
  - 1~2줄 설명
- 또는 텍스트 위주의 간결한 리스트

### 5. 작업 프로세스 또는 클라이언트 로고

**옵션 A — 프로세스**:
- 4단계: 1. 기획 → 2. 디자인 → 3. 피드백 → 4. 납품
- 각 단계 짧은 설명

**옵션 B — 클라이언트 로고**:
- 회색 라벨: "Worked with"
- 로고 5~8개 가로 배열

### 6. 후기 섹션 (서정적 톤)

**구성**:
- 섹션 헤더: 짧고 인상적 ("그들의 말")
- 후기 2~3개 (큰 인용문 형식):
  - 인용 부호 (큰 따옴표)
  - 후기 본문 (감성적, 구체적 표현)
  - 작성자 이름 + 회사/직책

### 7. 작업 의뢰 안내 (간결한 CTA)

**구성**:
- 섹션 헤더: "함께 작업하고 싶으세요?"
- 부제: 한 줄 (예: "흥미로운 프로젝트는 언제든 환영해요")
- 큰 이메일 주소 (CTA 역할):
  - 예: "hello@studio-ohgong.com"
- 또는 작은 컨택 폼:
  - 이름, 이메일, 메시지

### 8. 푸터 (간소화)

- SNS 링크 아이콘 (Instagram, Behance, Twitter)
- 이메일
- 카피라이트
- "포트폴리오용 샘플 작업" 작게

브랜드명: "스튜디오 오공(Studio Ohgong)"

분야: 브랜드 아이덴티티, 패키지 디자인, 포스터

콘텐츠 톤:
- 서정적이고 절제된 한국어
- 자기 자랑보다 작업에 대한 애정 표현
- 짧고 시적인 카피 ("오래 보고 싶은 디자인을 만들어요")

- 호버 효과 CSS transition
- Next.js 16 App Router 호환, TypeScript, Tailwind CSS 4
- 'use client' (필터/폼 상태 필요)
- 아이콘: lucide-react
- 푸터에 작게 "포트폴리오용 샘플 작업" 명시

전체 single React component로 출력. 파일명은 page.tsx로 가정.
