## 1. 기본 정보

- **유형**: 브랜드/포트폴리오형 (Brand / Portfolio)
- **목적**: 개인·스튜디오의 정체성을 보여주고 작품을 노출하며 의뢰로 연결한다
- **사용 디자인 시스템**: Dark Cosmic + Violet Accent — `#050510` 베이스 + 보라(`#a855f7`/`#c084fc`) 강조, 별·구체·radial wash 등 우주 모티프
- **레퍼런스**: 1인 스튜디오 / 작가 포트폴리오의 서정적·여백 강조 톤
- **샘플 컨셉**: 1인 그래픽 디자인 스튜디오 "Studio Ohgong"
- **예상 작업 시간**: 시안 25분 + 통합 5분 = 30분 (이상적인 케이스 A)

## 2. 적합한 사업 (고객 매칭용)

이 템플릿이 잘 맞는 케이스:
- 프리랜서 그래픽/UX/일러스트 디자이너
- 1인 사진작가 / 영상감독 / 모션 디자이너
- 소형 디자인·브랜딩 스튜디오 (1–5인)
- 작가·일러스트레이터·도예가 등 작품 중심 크리에이터
- 인테리어·플로리스트·세라믹 등 시각 작업 위주의 1인 사업
- "회사 소개"보다 "사람과 작품"을 보여주는 게 강한 비즈니스

핵심 공통점: **포트폴리오 자체가 영업이 되는 비즈니스**

## 3. 구현된 섹션 구조

실제 코드(`page.tsx`)에서 확인된 9개 영역 (위에서 아래):

### 섹션 1: 고정 네비게이션 (fixed pill)
- **구성**: 화면 최상단에 고정된 라운드 알약 (`fixed top-0 ... mt-3`), 좌측 브랜드 닷+로고, 중앙 5개 인페이지 앵커, 우측 "의뢰하기" CTA
- **인터랙션**: `backdrop-filter: blur(20px)` (`.nav-blur`), 모바일에서는 중앙 메뉴 숨김
- **앵커**: `#about` `#work` `#services` `#process` `#voices` (모두 실제 섹션 ID와 매칭)
- **콘텐츠 슬롯**: 브랜드명, 5개 메뉴 라벨, CTA 텍스트

### 섹션 2: 히어로 (#top)
- **구성**: 별이 깔린 풀화면, 가운데 정렬. 작은 eyebrow + 거대 H1 (64→136px 반응형) — 두 번째 줄 보라 그라데이션 텍스트 + 서브카피 2줄 + 듀얼 CTA + 하단 보라 구체(sphere) 비주얼
- **인터랙션**: 진입 시 `.rise-1` ~ `.rise-5` 순차 등장 애니메이션 (CSS keyframe `ohg-rise`)
- **콘텐츠 슬롯**: eyebrow, H1 두 줄, 서브카피, primary/secondary CTA, 구체 비주얼

### 섹션 3: 자기소개 (#about)
- **구성**: 좌(7) 큰 헤딩 + 본문 2단락 + CTA / 우(5) 프로필 카드 + 메타 정보
- **콘텐츠 슬롯**: H2, 본문 2~3단락, 프로필 이미지, 시작 연도·도시 등 메타

### 섹션 4: 분야/서비스 (#services)
- **구성**: 헤더 + 4개 서비스. 1번 카드(`md:col-span-2`)는 와이드 + 체크리스트 4개, 2~3번은 1/3 크기 카드, 4번 카드는 또 와이드(부가 메타 라인)
- **인터랙션**: `.reveal` IntersectionObserver 페이드 인
- **콘텐츠 슬롯**: 섹션 헤더, 서비스 4개 (각: 번호/제목/설명) + 1번 카드 체크리스트 4개

### 섹션 5: 프로세스 (#process)
- **구성**: 좌(5) 텍스트 + CTA / 우(7) 보라 그라데이션 보더로 둘러싼 "프로세스 카드". 4단계 칩 (01 기획 / 02 디자인 / 03 피드백 / 04 납품) + 1단계 상세 (3개 체크 + 다음 단계 버튼) + 하단 4분할 기간 표
- **인터랙션**: 칩에 `aria-pressed="true"`로 활성 단계 표시 (정적), reveal 페이드
- **콘텐츠 슬롯**: 좌측 H2 + 본문, 프로젝트 제목/날짜, 4단계 명칭·기간, 1단계 체크리스트 3개

### 섹션 6: 작업 갤러리 (#work)
- **구성**: 헤더 + 카테고리 필터 칩 4개(All/Identity/Package/Editorial) + 12 컬럼 메이슨리 그리드. 각 작품 카드 = 종횡비 다양한 이미지 + 호버 시 오버레이로 카테고리·연도·제목 노출
- **인터랙션**: `useState<Category>` 필터 토글, hover 시 카드 위로 -4px / 이미지 1.05x 줌
- **콘텐츠 슬롯**: 작품 7개 (제목, 메타, 연도, 카테고리, 이미지, 그리드 span, aspect)

### 섹션 7: 후기 (#voices)
- **구성**: 헤더(별점 칩 4.9/5 + H2 "그들의 말") + 3컬럼 후기 카드 6개. 카드는 인용문 + 아바타(그라데이션 원) + 이름 + 회사·직책
- **콘텐츠 슬롯**: 평균 별점, 클라이언트 수, 후기 6개 (인용/이름/직책/아바타 그라데이션)

### 섹션 8: 마지막 컨택 (#contact)
- **구성**: 별 배경 + eyebrow + 거대 H2 + 서브카피 + 큰 이메일 CTA 버튼 + 컨택 폼 (이름, 이메일, 메시지, status 라인)
- **인터랙션**: `useState` 폼 + `console.log` + 제출 후 상태 라인 메시지 변경
- **콘텐츠 슬롯**: H2, 서브카피, 이메일 주소, 폼 라벨, 응답 안내

### 섹션 9: 푸터
- **구성**: 좌측 브랜드+슬로건+SNS 아이콘(Instagram/Behance/Twitter) / 우측 메뉴 링크 + 이메일 / 하단 카피라이트 + `<Link>` 백링크 + "포트폴리오용 샘플 작업입니다"
- **콘텐츠 슬롯**: SNS URL, 이메일, 메뉴 4개, 푸터 카피

## 5. 기술 스택

- Framework: Next.js 16 App Router
- Language: TypeScript
- Styling: Tailwind CSS 4 + 인라인 `<style dangerouslySetInnerHTML>` (약 280줄, 모두 `.ddpage-ohgong` 스코핑)
- 아이콘: `lucide-react` (Instagram, Twitter, Star, ArrowRight)
- 클라이언트 컴포넌트: 파일 최상단 `'use client'`
- 이미지: placehold.co URL (보라 톤 placeholder)
- 폼: `console.log('contact submit', ...)` + 상태 라인 메시지
- 폰트: Pretendard / Bricolage Grotesque / Inter Tight 인라인 지정
- 한글 줄바꿈: `break-keep` 유틸 + `<main>` 루트에 직접 적용
- 푸터: `<Link href="/portfolio">` 백링크 + "포트폴리오용 샘플 작업" 명시

## 6. 고객에게 받을 정보 체크리스트

### 필수 정보 — 브랜드 / 사람
- [ ] **스튜디오/개인 이름** (네비, 푸터, 모든 헤딩)
- [ ] **한 줄 슬로건** (히어로 H1 — 두 줄 가능, 한 단어 그라데이션 강조)
- [ ] **분야 라벨** (eyebrow — 예: "Graphic Designer", "Photographer")
- [ ] **자기소개 본문** 2~3단락 — 정체성 + 철학 + 함께 일한 사람

### 작품 갤러리 (필수 — 페이지의 주인공)
- [ ] **작품 6~9개**, 각 항목:
  - 작품 제목
  - 카테고리 (3~4종으로 분류, 필터칩이 됨)
  - 연도
  - 메타 한 줄 (예: "Brand Identity · 2024")
  - 이미지 (다양한 종횡비 권장: 1:1, 3:4, 4:3, 16:9)
- [ ] 카테고리 목록 (현재: identity / package / editorial)

### 서비스 (4개)
- [ ] 서비스 4개, 각: 번호 라벨 + 영문 제목 + 한국어 1~2줄 설명
- [ ] 1번(가장 자주 의뢰받는) 카드의 체크리스트 4개

### 프로세스
- [ ] **4단계** 명칭 + 각 단계 소요 기간 (예: 2주 / 4–6주 / 2주 / 1주)
- [ ] 샘플 프로젝트 이름 + 진행 월 (프로세스 카드 헤더용)
- [ ] 1단계 세부 체크 3개 (예: "첫 인터뷰", "레퍼런스 큐레이션", "방향성 정리")

### 후기 (6개)
- [ ] 후기 6개, 각: 인용문 + 작성자 이름 + 회사/직책 (실명 비공개 시 마스킹)
- [ ] 평균 별점 + 누적 클라이언트 수 (예: 4.9 / 5 — 40+ clients)

### 컨택
- [ ] **이메일 주소** (큰 CTA 버튼)
- [ ] SNS 링크 3개 (Instagram / Behance / Twitter — 다른 채널 가능)
- [ ] 응답 안내 한 줄 (예: "보통 2–3일 안에 답장 드립니다")

### 비주얼 자산
- [ ] 대표 작업 이미지 7개+ (해상도 ≥ 1200px, 다양한 비율)
- [ ] 프로필 사진 (자기소개 섹션용, 선택)
- [ ] SNS 핸들

### 푸터
- [ ] 사업장/스튜디오 주소 (선택)
- [ ] 카피라이트 표기

## 7. 권장 디자인 톤

- 1순위: **Dark Cosmic** (현재 시안) — 보라 그라데이션 + 별 + 구체. 작품이 어두운 배경에서 도드라짐
