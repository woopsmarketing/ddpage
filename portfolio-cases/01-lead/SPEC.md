## 1. 기본 정보

- **유형**: 리드/DB 수집형
- **목적**: 사전예약 이메일 수집 (정식 오픈 전 자산 확보). 단일 액션 — 결제·로그인 없이 이메일 한 줄
- **샘플 브랜드**: 런온(LearnOn) — 큐레이션 학습 플랫폼
- **디자인 톤**: 다크 히어로(`#0a0b0d`) + Royal Blue(`#0052ff`) 액션 + 본문은 라이트 + 4가지 파스텔(민트/피치/스카이/크림)로 카테고리 구역 차별화
- **타이포**: Inter + Noto Sans KR (display는 큰 -2.2px tracking, JetBrains Mono로 숫자 강조)

## 3. 구현된 섹션 구조

`app/portfolio/lead/page.tsx`에서 확인된 14개 섹션:

### 섹션 1: Nav (`<Nav />`)
- **구성**: 다크 sticky 바. 좌측 로고(파란 dot + LearnOn), 중앙 메뉴 6개(왜 런온인가/카테고리/강사진/추천 강의/후기/자주 묻는 질문), 우측 "로그인" + "사전예약" 필 버튼
- **인터랙션**: `useEffect` + `IntersectionObserver`로 현재 보이는 섹션 자동 하이라이트 (`.active` 클래스)
- **콘텐츠 슬롯**: 로고 + 6개 메뉴 라벨 + 듀얼 우측 액션

### 섹션 2: Hero (`<Hero />`)
- **구성**: 다크 배경 + 그라데이션 라이트 효과(좌상 블루 / 우하 골드). 좌측 카피 + 인라인 이메일 폼, 우측 3개 플로팅 카드(배지 / 코스 미리보기 / 통계)
- **인터랙션**:
  - 폼: useState로 이메일 입력 + 제출 시 가짜 성공 메시지 표시
  - eyebrow에 pulse 애니메이션 (CSS keyframes)
  - 플로팅 카드 3종 각각 다른 float 애니메이션 (CSS)
- **콘텐츠 슬롯**:
  - eyebrow 라벨 ("사전예약 오픈 · 7일 한정")
  - h1 (3줄 헤드라인, 마지막 라인 컬러 강조)
  - lead 텍스트 + 강조 어구(25% 할인)
  - 이메일 입력 + CTA 버튼
  - form-micro 3개 체크 (30초/스팸 없음/언제든 해지)
  - 코스 카드: 카테고리 칩 / 제목 / 메타 / 진행률
  - 통계 카드: 라벨 / 큰 숫자 / 델타 / 미니 라인차트(SVG polyline)
  - 배지 카드: 라벨 + 큰 타이틀

### 섹션 3: LogoMarquee (`<LogoMarquee />`)
- **구성**: 회색 캡션 + 무한 가로 스크롤 로고 12개 (×2 복제로 seamless)
- **인터랙션**: CSS `@keyframes lp-marquee` 36초 linear infinite, hover 시 일시정지
- **콘텐츠 슬롯**: 12개 회사명 + 글리프 1글자

### 섹션 4: ValueProps (`<ValueProps />`) `#why`
- **구성**: 좌측정렬 섹션 헤더(label/h2/p) + 3카드 그리드 (아이콘 / 타이틀 / 본문 / 푸터 링크)
- **콘텐츠 슬롯**: 헤더 3개 슬롯 + 카드 3개 (아이콘 SVG / 타이틀 / 설명 / 푸터 텍스트)

### 섹션 5: Categories (`<Categories />`) `#categories`
- **구성**: 4×2 정사각형 카드 그리드 (8개 카테고리, 컬러는 cat-blue/ink/mint/peach/cream/sky/ink2/strong 8종)
- **콘텐츠 슬롯**: 카테고리당 강의 개수 + 카테고리명 + 서브 설명

### 섹션 6: Instructors (`<Instructors />`) `#instructors`
- **구성**: 4카드 그리드. 카드당 그라데이션 정사각 사진(이니셜 글자 + 분야 태그) + 이름/경력 + 강의수/평점. 하단 중앙 "모두 보기" outlined 버튼
- **콘텐츠 슬롯**: 강사 4명 (이름/이니셜/경력/태그/강의수/평점)

### 섹션 7: FeaturedCourses (`<FeaturedCourses />`) `#courses`
- **구성**: 다크 섹션 + 3×2 카드 (6개 강의). 카드당 16:10 썸네일(그라데이션 + 카테고리 칩 + play 아이콘) + 제목 / 강사 메타 / 별점 / 가격(원가 취소선 + 할인가)
- **콘텐츠 슬롯**: 강의 6개 (썸네일 톤 / 카테고리 / 제목 / 메타 / 별점 / 리뷰수 / 원가 / 할인가)

### 섹션 8: Stats (`<Stats />`)
- **구성**: 라이트 회색 배경 + 4개 stat block (라벨/큰 mono 숫자/단위/델타/서브). 첫번째에만 델타("+1,204 어제 대비")
- **콘텐츠 슬롯**: 통계 4개 (라벨 / 숫자 / 단위 / 서브)

### 섹션 9: HowItWorks (`<HowItWorks />`)
- **구성**: 3카드 (01/02/03). 3번째는 dark accent. 카드당 stepnum / h4 / p / 우하단 데코 SVG
- **콘텐츠 슬롯**: 3단계 (번호 / 제목 / 설명)

### 섹션 10: Comparison (`<Comparison />`)
- **구성**: 3컬럼 비교 표 (기준 / 런온 강조컬러 컬럼 / 일반 플랫폼). 헤더 행 + 6개 비교 항목 (체크/엑스 또는 텍스트 값)
- **콘텐츠 슬롯**: 항목 6개 (기준명 / 런온 값 / 일반 값)

### 섹션 11: Testimonials (`<Testimonials />`) `#testimonials`
- **구성**: 3×2 카드 (6개 후기). 카드당 별점 / blockquote / 아바타(이니셜 + 6가지 톤) + 이름 + 메타
- **콘텐츠 슬롯**: 후기 6개 (본문 / 이름 / 직업 / 아바타 톤)

### 섹션 12: FAQ (`<FAQ />`) `#faq`
- **구성**: 중앙 헤더 + 6개 아코디언. 펼침 시 + 아이콘이 45° 회전(× 모양). 한 번에 하나만 열림
- **인터랙션**: useState<number | null>로 open index 관리. 클릭 시 토글
- **콘텐츠 슬롯**: FAQ 6개 (질문 / 답변)

### 섹션 13: FinalCTA (`<FinalCTA />`) `#final-cta`
- **구성**: 다크 풀와이드 + 중앙 그라데이션. eyebrow / h2 / lead / 카운트다운 칩 / 폼 / form-micro
- **인터랙션**:
  - 카운트다운: useEffect + setInterval(1초). localStorage `lp_cd_end`로 7일 끝 시점 저장 (새로고침 시에도 유지)
  - 폼: 히어로와 동일한 SignupForm 컴포넌트 (formKey만 다름)
- **콘텐츠 슬롯**: eyebrow / h2 (2줄) / lead / 폼

### 섹션 14: Footer (`<Footer />`)
- **구성**: 라이트 5컬럼(브랜드 1.4fr + 메뉴 4컬럼). 브랜드 컬럼 = 로고+소개+SNS 3개(X/IG/YT). 메뉴 = 서비스/회사/고객지원/정책. 하단 사업자 정보 + 사이트맵/접근성 / 최하단 포트폴리오 표시 + `/portfolio` 복귀 링크
- **콘텐츠 슬롯**:
  - 브랜드 한 줄 소개
  - SNS 링크 3개
  - 메뉴 컬럼 4개 × 4개 항목 = 16개
  - 사업자 정보 3줄 (회사/대표/등록번호/통판신고/주소/고객센터)
  - 카피라이트
  - 사이트맵/접근성 보조 링크
  - 포트폴리오 안내 + `/portfolio` 링크

## 5. 기술 스택

- Framework: Next.js 16.2.6 App Router
- Language: TypeScript
- Styling: **인라인 `<style dangerouslySetInnerHTML>` 블록 (`.lp` 접두로 스코프됨)**. Tailwind는 외부 페이지(목록 등)만 사용
- 아이콘: 인라인 SVG (lucide-react 미사용 — 원본 HTML이 인라인 SVG였고 톤 통일 우선)
- 클라이언트 컴포넌트: 파일 최상단 `'use client'` (state/effect 여러 곳)
- 이미지: 0장 (모두 SVG/그라데이션/colored div로 대체)
- 폼: 가짜 성공 (`console.log` + 상태 토글)
- 라우팅: `next/link`로 `/portfolio` 복귀 링크 1개
- 글로벌 누수 방지: 모든 generic 셀렉터(`html`/`body`/`a`/`p`/`h1-4` 등)에 `.lp` 접두
