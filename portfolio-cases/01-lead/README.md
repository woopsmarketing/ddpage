# 01-lead 케이스

## 사용법
고객이 "리드/DB 수집형" 유형을 선택하면:

1. `SPEC.md`의 **6. 고객에게 받을 정보 체크리스트**를 그대로 양식으로 전달
2. 고객 답변 수령 후, `PROMPT.md`의 [샘플 콘텐츠] / [대괄호] 부분을 고객 정보로 교체
3. Claude.ai에서:
   - 다크 히어로 + 파스텔 카테고리 톤 (또는 동등) 선택
   - 레퍼런스 이미지 첨부 (있다면)
   - 수정한 프롬프트로 시안 요청
4. 시안 받으면 `/portfolio-integrate <소스파일/폴더> lead "리드/DB 수집형"` 슬래시 커맨드로 통합
