## 08-profile / PROMPT.md

[랜딩페이지 유형]: 1인 프로필형 (Link in Bio 대체)

[목적]: 1인 크리에이터 브랜드 허브 — SNS 프로필 링크용

[전환 핵심]
- 모바일 퍼스트 (SNS 인앱 브라우저에서 90% 열림)
- 빠른 탐색 (한 화면에 핵심 링크 다)
- 개인 브랜드 + 친근감

[참고 레퍼런스]
첨부 이미지의 중앙 정렬, 모바일 퍼스트, 깔끔한 링크 카드 응용.

[페이지 구조 - 순서대로]

### 1. 상단 프로필 섹션 (첫인상)

**세부 요소**:
- 배경: 단색 또는 부드러운 그라데이션
- 원형 프로필 이미지 (중앙, placeholder)
  - 크기: 데스크탑 120px, 모바일 100px
- 이름 (큰 타이포):
  - 예: "김지온"
- 한 줄 소개 (작은 글씨, 부드러운 톤):
  - 정체성 표현
  - 예: "느린 글을 쓰는 사람"
  - 또는 "에세이 작가 · 독립 출판인"
- 위치 표시 (선택, 작게): 📍 서울

### 2. 짧은 자기소개 (2~3문장)

**구성**:
- 가운데 정렬 텍스트
- 부드러운 톤
- 예: "글로 일상을 모으는 사람입니다. 매주 한 편의 에세이를 쓰고, 가끔 책을 만듭니다."
- 작은 글씨, 절제된 표현

### 3. 메인 액션 버튼 (선택, 가장 강조하고 싶은 1~2개)

**구성**:
- 가장 강조하고 싶은 액션:
  - 예: "📚 최신 책 구매" (큰 버튼)
- 또는 메인 CTA 1개만

### 4. 링크 카드 5~7개 (Vertical Stack)

**구성**:
- 각 카드:
  - 아이콘 + 텍스트 + → 화살표
  - 호버 효과 (살짝 위로 / 그림자)
  - 클릭 가능 (a href)
- 카드 종류:
  - "📚 강의 보기" → 인프런 등 외부 링크
  - "📝 뉴스레터 구독" → 가입 페이지
  - "📷 인스타그램" → 인스타 프로필
  - "📺 유튜브 채널" → 유튜브
  - "📖 블로그" → 외부 블로그
  - "🎙️ 팟캐스트" → 스포티파이/유튜브
  - "💌 컨택" → 메일 또는 폼
- 카드 간 일정한 간격
- 모바일에서 풀폭, 데스크탑에서 max-w-md 중앙 정렬

### 5. 하이라이트 콘텐츠 (선택, 1~2개)

**구성**:
- 작은 라벨: "Latest" 또는 "최근 작업"
- 카드 1~2개:
  - 큰 이미지 placeholder (가로형 또는 정사각형)
  - 콘텐츠 제목
  - 한 줄 설명
  - 발행일 또는 카테고리
  - 클릭 시 외부 링크

### 6. SNS 아이콘 줄 (Quick links)

**구성**:
- 작은 아이콘 5~7개 (가로 정렬)
- Instagram, Twitter/X, YouTube, Threads, LinkedIn, Email 등
- 호버 시 색상 변경 또는 살짝 커짐

### 7. 푸터 (매우 간소)

- 카피라이트 또는 짧은 한 줄
- 예: "© 2026 김지온"
- 또는 "Made with ❤️"
- "포트폴리오용 샘플 작업" 작게
