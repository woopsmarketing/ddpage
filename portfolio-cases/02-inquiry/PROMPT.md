[전환 핵심]
- 상담 요청은 "리스크 인지"가 높은 액션. 신뢰가 모든 것.
- 자격 증명 + 사회적 증거 + 결과 사례를 페이지 전반에 분산
- "이 사람한테 맡겨도 되겠다"를 8초 안에 결정짓게

[참고 레퍼런스]
첨부 이미지의 톤, 레이아웃, 정보 밀도 응용. 디자인 시스템은 시스템 가이드 우선.

[페이지 구조 - 순서대로]

### 1. 히어로 섹션 (전문성 + 친근감 동시에)

**세부 요소**:
- 상단 라벨: 전문성 신호 ("국세청 등록 세무사 / 12년 경력")
- 메인 헤드라인:
  - 패턴: "[타겟]을 위한 [전문 분야] 상담"
  - 예: "1인 사업자를 위한 절세 컨설팅"
  - 또는 결과형: "세금 30% 줄여드린 1인 사업자 200명+"
- 서브카피: 누가/어떤 문제를 해결해주는지 명시
- 듀얼 CTA:
  - Primary: "💬 카톡 상담 (3분 안에 답변)"
  - Secondary: "📞 전화 문의"
  - 응답 시간 명시가 전환율 +25%
- 신뢰 신호 (CTA 아래 작게):
  - "초기 상담 무료 · 누적 상담 1,200건"
- 우측 또는 하단:
  - 전문가 본인 사진 (placeholder, 정면 미소)
  - 또는 사무실 공간 이미지

### 2. 사회적 증거 + 자격 증명 (히어로 직후 배치)

**구성**:
- 큰 숫자 3~4개 (각 의미와 함께):
  - "1,247건" — 누적 상담 건수
  - "12년" — 업계 경력
  - "98%" — 재의뢰율
  - "200만원+" — 평균 절세액 (예시)
- 자격증/배지 가로 배열:
  - 한국세무사회 회원
  - 국세청 등록번호
  - 인증 마크 (placeholder 이미지)
- 미디어 노출 또는 기업 로고 (선택)

### 3. 제공 서비스 (3~4개 카드)

**구성**:
- 카드당:
  - 아이콘
  - 서비스명
  - 한 줄 설명
  - "시작 가격: 5만원~" (가격 공개가 신뢰 신호)
  - "자세히 보기" 또는 "이 서비스로 상담"

### 4. 핵심 차별점 섹션 (Why Me)

**구성**:
- 섹션 헤더: "왜 [브랜드명]일까요?"
- 3가지 차별점 (좌측 텍스트 + 우측 이미지 교차):
  - 점 1: 일반 회계법인 vs 1인 사업자 특화
  - 점 2: 카톡 상시 응대 vs 일반 사무소
  - 점 3: 절세 시뮬레이션 제공
- 각 차별점은 '비교' 형태로 표현 (대조가 설득력 강화)

### 5. 후기 섹션 (가장 강력한 사회적 증거)

**구성**:
- 섹션 헤더: "실제 고객의 변화"
- 후기 카드 4~6개:
  - 후기 인용문 (구체적 결과 포함)
  - 작성자 이름 + 직업/사업명
  - 별점 (5점 만점)
  - 처리 내용 한 줄 (예: "법인 전환 + 절세 컨설팅")
- 가능하면 사진 placeholder 추가

### 6. 진행 프로세스 (불안 해소)

**구성**:
- 4단계 가로 또는 세로 타임라인:
  1. 카톡 문의 (즉시 응답)
  2. 무료 상담 (30분 화상 또는 대면)
  3. 견적 + 진행 제안 (1~2일)
  4. 본 계약 + 작업 시작
- 각 단계에 예상 소요 시간 명시
- 마지막 단계에 "환불 보장" 또는 "만족 시 본계약" 강조

### 7. 자주 묻는 질문 (전환 차단 해소)

5~6개 FAQ ('use client' 아코디언):
- "상담만 받고 결정해도 되나요?" (Yes 명확히)
- "비용이 부담스러운데요" → 가격 정책 설명
- "지방 사업자도 가능한가요?" → 비대면 안내
- "처음이라 뭘 준비해야 할지 모르겠어요" → 준비물 안내
- "다른 세무사와 뭐가 다른가요?"
- "환불 정책은 어떻게 되나요?"

### 8. 상담 신청 폼 섹션

**구성 (마찰 최소화)**:
- 헤더: "지금 무료 상담 신청"
- 필드:
  - 이름
  - 연락처 (전화 또는 카톡 ID)
  - 사업 형태 (선택: 개인사업자/법인/예비창업/기타)
  - 상담 내용 (간단히)
- 동의 체크박스 (개인정보 처리 동의)
- 큰 CTA 버튼: "무료 상담 신청"
- 버튼 아래: "1영업일 안에 답변드립니다"

### 9. 푸터

- 사업자 정보 (사업자명, 등록번호, 통신판매업 신고번호)
- 연락처 (전화, 카톡, 이메일)
- 사업장 주소
- 약관 / 개인정보 처리방침
- "포트폴리오용 샘플 작업" 작게 명시
