## 1. 기본 정보

- **유형**: 상담 문의형 (Inquiry / Consultation Lead)
- **목적**: 전문가 서비스에 대한 신뢰를 빌드하고, 카톡·전화·폼 3가지 경로로 무료 상담 문의를 받는다
- **사용 디자인 시스템**: Airbnb-ish 미니멀 (화이트 + `#ff385c` 코럴 포인트)
- **레퍼런스**: Airbnb / 의료·전문가 컨설팅 사이트의 절제된 신뢰 톤
- **샘플 컨셉**: 1인 사업자 전문 세무 컨설팅 "택스메이트"
- **예상 작업 시간**: 시안 15분 + 통합 5분 = 20분 (이상적인 케이스 A)

---

## 2. 적합한 사업 (고객 매칭용)

이 템플릿이 잘 맞는 케이스:
- 세무 / 회계 / 노무 / 법무 전문가 사무소
- 헬스 / 미용 / 의료 클리닉 상담 페이지
- 인테리어 / 리모델링 / 건축 견적 받기
- 컨설팅 / 코칭 / 강의 1:1 상담
- 부동산 / 보험 / 자산관리 상담
- 중소형 B2B 서비스 (의뢰형)

핵심 공통점: **결제 전 "상담"이라는 한 단계가 끼는 비즈니스**

## 3. 구현된 섹션 구조

실제 코드(`page.tsx`)에서 확인된 9개 섹션, 위에서 아래 순서:

### 섹션 1: 네비게이션 (sticky)
- **구성**: 좌측 브랜드 마크 + 텍스트, 중앙 5개 인페이지 앵커, 우측 카톡 CTA
- **인터랙션**: `sticky top-0 z-50`, 호버 시 배경 토닝
- **앵커**: `#services` `#why` `#reviews` `#process` `#faq` (모두 실제 섹션 ID와 매칭)
- **콘텐츠 슬롯**: 브랜드명, 5개 메뉴 라벨, CTA 버튼 텍스트

### 섹션 2: 히어로
- **구성**: 좌(7) — 자격 라벨 + H1(코럴 강조) + 서브카피 + 듀얼 CTA(카톡/전화) + 신뢰 체크 3개 / 우(5) — 인물 이미지 + 만족도 플로팅 배지 + 평균 절세액 플로팅 카드
- **콘텐츠 슬롯**: 상단 라벨, H1, 서브카피, primary/secondary CTA, 신뢰 신호 3개, 인물 사진, 만족도, 평균 결과 수치

### 섹션 3: 통계 + 자격 (회색 배경)
- **구성**: 4개 큰 숫자 카드 (누적 상담·경력·재의뢰율·평균 절세액) + 자격 인증 4개 배지 가로 배열
- **인터랙션**: `+`/`%`/단위는 코럴 강조 분리 렌더
- **콘텐츠 슬롯**: 통계 4개 (숫자 + 라벨 + 캡션), 자격증/인증 배지 4개

### 섹션 4: 제공 서비스 (#services)
- **구성**: 4컬럼 카드 그리드 (모바일 1열). 각 카드 = 아이콘 + 제목 + 설명 + 시작 가격 + "상담" 인라인 링크
- **인터랙션**: `ddpage-inquiry-hover-float` (호버 시 그림자 부드럽게)
- **콘텐츠 슬롯**: 서비스 4개 (아이콘, 제목, 1줄 설명, 가격, 단위)

### 섹션 5: 차별점 / Why Me (#why, 회색 배경)
- **구성**: 차별점 3개를 좌우 교차 레이아웃(텍스트/이미지)으로 배치. 각 블록 안에 "일반 vs 우리" 2분할 비교 카드
- **콘텐츠 슬롯**: 차별점 3개 (번호 라벨, 제목, 본문, bad/good 비교 한 줄, 이미지)

### 섹션 6: 후기 (#reviews)
- **구성**: 헤더 우측에 큰 평균 별점(4.96) + 별 5개 + 후기 수. 본문은 3컬럼 후기 카드 6개. 카드 = 별점 + 인용문 + 처리 내역 + 아바타+이름+직업
- **콘텐츠 슬롯**: 평균 별점, 후기 수, 후기 6개 (인용, 처리 메타, 이름, 직업, 아바타)

### 섹션 7: 진행 프로세스 (#process, 회색 배경)
- **구성**: 4단계 카드 (모바일 1열, 데스크탑 4열). 마지막 단계는 다크 카드로 환불 보장 강조. 하단에 "어느 단계든 중단 가능" 안내
- **콘텐츠 슬롯**: 단계 4개 (번호, 제목, 설명, 소요 시간, dark 여부)

### 섹션 8: FAQ (#faq)
- **구성**: 좌측 카피 + 카톡 CTA, 우측 `<details>` 6개. 첫 항목 기본 open. `Plus` 아이콘이 펼침 시 45도 회전
- **인터랙션**: 네이티브 `<details>` (JS 불필요), CSS transition으로 아이콘 회전
- **콘텐츠 슬롯**: FAQ 6개 (질문 + 답변)

### 섹션 9: 상담 신청 + 푸터
- **#contact 섹션**: 좌측 헤더 + 3개 연락 채널(카톡/전화/이메일) / 우측 상담 신청 폼 (이름, 연락처, 사업 형태 select, 상담 내용 textarea, 동의 체크박스, CTA)
- **인터랙션**: `useState` 폼 상태 + 제출 시 `console.log` + 인라인 성공 메시지
- **푸터**: 5/3/2/2 컬럼 그리드 (브랜드+슬로건 / 사업자 정보 / 연락처 / 정책 링크) + 하단 카피라이트 + "← 다른 포트폴리오 보기" + "포트폴리오용 샘플 작업입니다"

## 5. 기술 스택

- Framework: Next.js 16 App Router
- Language: TypeScript
- Styling: Tailwind CSS 4 + 인라인 `<style dangerouslySetInnerHTML>` (CSS는 약 40줄, 모두 `.ddpage-inquiry` 스코핑)
- 아이콘: `lucide-react` (MessageCircle, Phone, Mail, Check, Star, ArrowRight, Plus, Calendar, Wallet, TrendingUp, Building2)
- 클라이언트 컴포넌트: 파일 최상단 `'use client'` (폼 상태)
- 이미지: Unsplash CDN URL (인물·차별점·아바타)
- 폼: `console.log('lead-submit', form)` + 인라인 성공 메시지
- 폰트: Inter + Noto Sans KR 인라인 지정
- 한글 줄바꿈: `break-keep` 유틸 + CSS `word-break: keep-all` 글로벌 적용
- 푸터: `<Link href="/portfolio">` 포트폴리오 목록 백링크 + "포트폴리오용 샘플 작업" 명시
