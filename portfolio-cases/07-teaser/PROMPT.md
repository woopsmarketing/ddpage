### 1. 풀스크린 히어로 (메인 + 거의 전부)

**세부 요소**:
- 배경:
  - 풀스크린 비주얼 (어두운 톤 또는 그라데이션, placeholder)
  - 또는 미니멀한 단색 배경
- 상단 중앙: 브랜드 로고 (placeholder, 절제된 크기)
- 메인 카피 (큰 타이포, 2~3줄):
  - 미스터리 카피:
    - "곧 새로운 무언가가 시작됩니다"
    - "오래된 방식, 새롭게 정의합니다"
    - "[N]년의 준비, [N]일 후 공개"
  - 한국어로 자연스럽게
- 부제 (한 줄):
  - 카테고리 또는 약속 힌트
  - 예: "라이프스타일의 새로운 정의" / "당신의 일상을 바꿀 무언가"
- 카운트다운 타이머 (큰 디스플레이):
  - 일/시/분/초 ('use client', useEffect + setInterval)
  - 강조 컬러 또는 흰색
- 인라인 이메일 가입 폼:
  - 이메일 입력 + CTA 버튼
  - 버튼 문구: "사전예약하기" / "Notify me"
  - 가입 후 가짜 성공 메시지: "🎉 사전예약 완료! 가장 먼저 알려드릴게요"
- 신뢰 신호 (작게):
  - "이미 [N]명이 기다리고 있어요"

### 2. 짧은 티저 소개 (Why care)

**구성**:
- 짧은 텍스트 섹션 (3~4문장):
  - 1문장: 어떤 카테고리/문제에 대한 것
  - 2~3문장: 왜 다른지 (구체적 X, 호기심 자극)
  - 결론: "곧 만나요"
- 큰 여백, 절제된 타이포

### 3. 얼리버드 혜택 (가입 이유 강화)

**구성**:
- 섹션 헤더: "사전예약 멤버 혜택"
- 3가지 혜택 (3열 카드 또는 리스트):
  - 각각 아이콘 + 짧은 헤드라인 + 1줄 설명
  - 예:
    - "🎁 20% 평생 할인" — 첫 1년간 적용
    - "✨ 우선 입장" — 정식 출시 전 1주일 먼저
    - "📦 한정판 굿즈" — 사전예약자 한정 제공

### 4. 사전 공개 갤러리 (선택, 권장)

**구성**:
- 작은 라벨: "Sneak Peek" 또는 "살짝 공개"
- 흐릿하거나 모자이크 처리된 이미지 3~4개 (placeholder)
- 또는 디테일 컷 (전체는 안 보임)
- 호기심 자극

### 5. SNS 링크 아이콘 줄

**구성**:
- 짧은 카피: "Stay tuned" 또는 "소식 받기"
- SNS 아이콘 3~5개 (Instagram, X, YouTube 등)
- 큰 사이즈, 가로 정렬

### 6. 푸터 (간소화)

- 카피라이트만
- 매우 작은 글씨
- "포트폴리오용 샘플 작업" 작게
