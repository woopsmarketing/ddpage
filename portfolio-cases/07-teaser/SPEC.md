## 3. 구현된 섹션 구조

실제 코드(page.tsx)에서 확인된 섹션 순서.

### 섹션 1: 글로벌 네비 + 서브 네비 (2단 sticky)
- **구성**: 상단 44px 글로벌 바(로고/메뉴 6개/검색·신청), 그 아래 52px 서브 바(브랜드명/메뉴 6개/"지금 신청" pill 버튼)
- **인터랙션**: 양쪽 모두 `position: sticky` + backdrop blur, md 미만에서는 메뉴 hidden
- **콘텐츠 슬롯**:
  - 브랜드 로고 (SVG inline)
  - 메뉴: 소개·연사·일정·장소·티켓·FAQ (각 in-page anchor)
  - 우측 상단 "지금 신청" pill 버튼

### 섹션 2: 히어로 (`#overview`)
- **구성**: 풀폭 fog 배경, 중앙정렬. 작은 azure caption("제 3회 · 서울") → 거대 display 타이포 ("마컨2026.", weight 가벼움 mix) → subheading 2줄 → 카운트다운 4셀 → CTA 2개(애저 pill + chevron link) → 별점 trust strip → 정보 4셀 그리드(일시/장소/가격/정원, 정원에 caution 컬러 사용)
- **인터랙션**: useCountdown 훅(setInterval 1s)으로 D/H/M/S 실시간 업데이트
- **콘텐츠 슬롯**:
  - 카테고리 라벨, 메인 타이틀, 서브카피 2줄
  - 타겟 일시 (TARGET 상수)
  - CTA primary + secondary 문구
  - trust 지표 2종 (평점, 누적 참가자)
  - 4개 인포 셀 (라벨/값/보조)

### 섹션 3: Why Attend (`#why`)
- **구성**: 좌측 정렬 caption + 2줄 heading-lg, 그 아래 3열 카드 (fog 배경, 28px radius). 각 카드는 18px radius num-mark + heading-sm + 본문
- **인터랙션**: 없음
- **콘텐츠 슬롯**: 헤더 2줄 + 3개 카드(번호/제목/2~3문장)

### 섹션 4: Speakers (`#speakers`)
- **구성**: fog 배경, 중앙정렬 헤더 → 3열 그리드 카드 6개. 각 카드는 정사각 portrait(이니셜 초대형 텍스트가 18% 투명도로 배경) + 이름/역할·소속/세션 한 줄
- **인터랙션**: 없음 (호버 미사용)
- **콘텐츠 슬롯**: 연사 6명 × (이름/이니셜/직책/소속/세션 제목)

### 섹션 5: Schedule (`#schedule`)
- **구성**: 단일 컬럼 좁은 너비(980px), 시간별 타임테이블. 각 행은 grid 140px/1fr/200px (시간/세션/연사). `kind: 'break'` 행은 fog 배경 + 별도 스타일링
- **인터랙션**: 없음
- **콘텐츠 슬롯**: 타임테이블 10행 (등록·키노트 6세션·점심·패널·클로징)

### 섹션 6: Venue (`#venue`)
- **구성**: 2열. 좌측 map-tile(가짜 격자선 + azure pin + 라벨), 우측 흰 카드에 주소·아이콘 3행(지하철/주차/입장) + "길찾기 열기" 링크
- **인터랙션**: 없음
- **콘텐츠 슬롯**: 주소/층호수, 교통/주차/입장 안내 3행

### 섹션 7: 지난 회차 갤러리 + 후기 (`#gallery`)
- **구성**: 헤더는 flex 좌우 분리. 6개 그라데이션 타일(`t-1`~`t-6` 색상 변형) 4:3 비율, 각 타일 좌하단 caption. 그 아래 3열 후기 카드
- **인터랙션**: 없음 (이미지 placeholder = CSS gradient)
- **콘텐츠 슬롯**: 갤러리 6컷 caption, 후기 3건 (별점/인용/이름/경력)

### 섹션 8: Tickets (`#tickets`)
- **구성**: 3열 가격 카드. 첫 번째(얼리버드)는 옵시디언 다크 + 잔여좌석 표시, 나머지 2개(정가/그룹)는 흰 카드. 각 카드: 라벨 → 제목 → 가격(취소선 가능) → 부가설명 → 체크리스트 → CTA pill
- **인터랙션**: 없음 (정적 카드)
- **콘텐츠 슬롯**: 티켓 3종 × (라벨/제목/가격/부설명/혜택 5종/CTA), 하단 환불 정책 안내 1줄

### 섹션 9: Apply Form (`#apply`)
- **구성**: 캡션 + heading-lg + 서브카피. 폼: 2열(이름·연락처) → 1열 이메일 → 사업 형태 셀렉트 → 3개 티켓 라디오 타일(상태) → 동의 체크박스 3개 → 큰 azure 제출 버튼 → 캡션
- **인터랙션**:
  - `useState` 티켓 타입 (early/regular/group) — 클릭 시 `is-selected` 토글
  - `onSubmit` form 핸들러 (preventDefault → console.log → 성공 박스 표시)
  - `submitted` state 성공 메시지 페이드인
- **콘텐츠 슬롯**: 이름/연락처/이메일/사업형태 셀렉트 5옵션/티켓 라디오 3종/동의 3행

### 섹션 10: FAQ (`#faq`)
- **구성**: 캡션 + heading-lg + 6개 FAQ. 각 항목은 trigger 버튼(질문 + plus 아이콘) + body. open 상태에서 chev 45° 회전 + body max-height 확장
- **인터랙션**: `useState<number | null>` 단일 열림 (기본 0번 열림), 토글
- **콘텐츠 슬롯**: 6 Q&A (주차/당일입장/환불/식사/녹화본/드레스코드)

### 섹션 11: Final CTA
- **구성**: 거대한 라운드 다크 박스(96px 패딩) + 상단 라디얼 azure 글로우 + 펄스닷 + "마감 임박" pill → 헤딩 → 서브카피 → 카운트다운 다크 셀 4개 → azure CTA → 캡션
- **인터랙션**: 펄스닷 keyframes 애니메이션(`ddpage-makecon-pulse`), 카운트다운 공유
- **콘텐츠 슬롯**: 잔여 인원, 헤드라인 1줄, 서브카피 2줄, CTA

### 섹션 12: Footer
- **구성**: 4컬럼(브랜드 2칸/문의/팔로우) → 구분선 → 중앙 정렬 영역에 `<Link href="/portfolio">← 다른 포트폴리오 보기</Link>` + 카피라이트 + "포트폴리오용 샘플 작업입니다"
- **콘텐츠 슬롯**: 로고/약식 소개, 문의 3행, SNS 3링크

## 5. 기술 스택

- Framework: Next.js 16 App Router
- Language: TypeScript (strict)
- Styling: Tailwind CSS 4 + scoped inline `<style>` (약 300줄, `.ddpage-makecon` 접두)
- 아이콘: lucide-react (Check, X, Plus, Search, MapPin, Train, Building2)
- 클라이언트 컴포넌트: 파일 전체 `'use client'` (카운트다운/폼/FAQ 상태)
- 폰트: SF Pro Display/Text + Inter fallback
- 이미지: 없음 (모두 CSS 그라데이션 / SVG inline / 텍스트 이니셜)
- 폼: console.log + 로컬 success state
