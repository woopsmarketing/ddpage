## 06-sales / PROMPT.md

[랜딩페이지 유형]: 세일즈/구매 전환형 (롱폼)

[목적]: 긴 스토리텔링으로 강한 구매 전환 — 정보성 상품에 최적

[전환 핵심]
- 이건 단순 페이지가 아니라 "글로 된 영업맨"
- 페인 자극 → 솔루션 제시 → 증명 → 안심 → 결제
- 충분히 길어야 함 (스크롤 깊이가 신뢰감)
- 가격 공개 위치 신중히 (보통 80% 지점)

[참고 레퍼런스]
첨부 이미지의 정보 밀도 + 강한 후킹 + Before/After 패턴 + 후기 디자인 응용.
충분히 길게, 정보가 풍부하게.

[페이지 구조 - 순서대로]

### 1. 히어로 섹션 (가장 강력한 후킹)

**전환의 60% 결정 — 디테일 최우선**

**세부 요소**:
- 상단 알림 바: "🎁 [N]월 [N]일까지 얼리버드 50% 할인"
- 작은 라벨 (타겟 명시):
  - 예: "1인 사업자, 프리랜서, 부업 시작자를 위한"
- 메인 헤드라인 (큰 타이포, 2~3줄):
  - 패턴 A (결과 약속): "30일 만에 SEO로 월 100만원 추가 매출 만들기"
  - 패턴 B (문제 해결): "광고비 0원, 검색 1페이지에 노출되는 방법"
  - 패턴 C (역설/궁금증): "유튜브 안 하고도 매출 10배 늘린 1인 사업자의 비밀"
  - 구체적 숫자/시간/결과 필수
- 서브카피 (1~2문장):
  - 누구를 위한 / 어떤 방법으로 / 어떤 결과
- 메인 비주얼:
  - 강의 미리보기 영상 placeholder (16:9 박스, 재생 버튼)
  - 또는 강사 + 결과물 이미지
- CTA 버튼 (큰 사이즈):
  - "지금 시작하기 (50% 할인)" + 화살표
- 보조 정보 (CTA 아래):
  - "✅ 평생 소장 · ✅ 환불 보장 · ✅ 카드/계좌이체"
- 신뢰 신호:
  - "이미 [숫자]명이 수강 중 · 평점 4.9/5"

### 2. 페인 포인트 섹션 (공감 형성 — "이거 나야!")

**구성**:
- 섹션 헤더: "혹시 이런 경험 있으세요?"
- 3~5가지 페인 포인트 (카드 또는 리스트):
  - 각 페인 포인트:
    - 빨간 X 또는 부정 아이콘
    - 짧은 묘사 (구체적 상황)
    - 감정 강조 카피
  - 예:
    - "광고비 30만원 썼는데 매출은 그대로"
    - "블로그 글 100개 썼는데 검색에 안 나옴"
    - "경쟁사는 잘 되는데 나는 안 됨"
- 마지막 강조 카피: "다 겪어봤습니다. 그래서 만들었어요."

### 3. 솔루션 도입 ("이게 답입니다")

**구성**:
- 큰 헤드라인 (변화의 시작):
  - 예: "이제 더 이상 시간 낭비하지 마세요"
- 솔루션 한 줄 정의:
  - 예: "[브랜드명] = 검증된 SEO 방법론을 30일 안에 배우는 코스"
- 핵심 가치 3개 (간단히):
  - "검증된 방법론 · 평생 소장 · 실시간 코칭"

### 4. 변화 전후 (Before / After)

**가장 효과 좋은 섹션 중 하나**

**구성**:
- 섹션 헤더: "수강 전 vs 수강 후"
- 좌우 2열 비교:
  - 좌측 (Before, 회색/빨강):
    - "광고에 의존" / "결과 없음" / "막막함" 등 5~7개
  - 우측 (After, 강조 컬러):
    - "유기적 트래픽" / "검색 1페이지" / "월 100만원+ 매출" 등 5~7개
- 좌측에서 우측으로 화살표 또는 그라데이션

### 5. 강사 소개 (Authority 강화)

**구성**:
- 큰 사진 placeholder (강사 본인)
- 이름 + 한 줄 정체성
- 자격/경력 배지 4~6개:
  - "○○대학교 졸업"
  - "○○회사 마케팅 디렉터"
  - "누적 강의 1,200명"
  - "유튜브 ○만 구독자"
- 3~4문장 소개 (스토리 위주)

### 6. 핵심 혜택 5~7개 (Outcome-focused)

**구성**:
- 섹션 헤더: "이 코스에서 얻게 될 것"
- 각 혜택:
  - 큰 아이콘
  - 헤드라인 (결과 중심)
  - 1~2줄 설명
- 기능(Feature)이 아니라 결과(Outcome)로 작성
- 예:
  - ❌ "10시간 강의 영상"
  - ✅ "키워드 분석부터 글 작성까지, 7일 안에 실행 가능"

### 7. 사회적 증거 — 후기 (대량 노출)

**구성**:
- 섹션 헤더: "실제 수강생들의 결과"
- 후기 카드 6~10개 (스크롤 가능 그리드 또는 카루셀):
  - 각 후기:
    - 본문 (구체적, 결과 포함)
    - 작성자 이름 + 직업/사업
    - 별점 5/5
    - 처리 결과 (예: "수강 30일 후 월 매출 80만원 추가")
  - 가능하면 사진 placeholder
- 마지막에 "외 수강 후기 [N]개+"

### 8. 콘텐츠 미리보기 (커리큘럼)

**구성**:
- 섹션 헤더: "어떤 내용이 들어있나요?"
- 모듈/챕터 5~8개 ('use client' 아코디언):
  - 각 모듈:
    - 헤더 (모듈명 + 강의 수 + 총 시간)
    - 펼치면 강의 리스트 (5~10개)
- 미리보기 영상 1~2개 (선택, 무료 공개분)

### 9. 보너스 항목 (Stacking value)

**구성**:
- 강조 박스 ("BONUS!")
- 보너스 3~4개:
  - 각각 가치 표시 ("99,000원 상당")
  - 짧은 설명
- 총 가치 합계 강조:
  - "총 [N]원 가치, 본 코스 가격에 모두 포함"

### 10. 가격 섹션 (80% 지점, 모든 가치 노출 후)

**구성**:
- 섹션 헤더: "투자할 가치가 충분한 가격"
- 가격 카드 (강조):
  - 정가 (취소선): "799,000원"
  - 할인가 (큰 글씨): "399,000원"
  - 할인율 배지: "50% OFF"
  - 분할 결제 안내: "월 33,250원 (12개월 무이자)"
- 포함 항목 체크리스트:
  - 본 코스 + 보너스 5개 + 평생 소장 + 환불 보장
- 큰 CTA 버튼: "지금 시작하기"
- 버튼 아래: 결제 수단 아이콘 (카드, 계좌이체, 카카오페이)

### 11. 환불 보장 / 리스크 제거

**구성**:
- 강조 박스 (방패/보장 아이콘):
- 헤드라인: "100% 환불 보장"
- 본문: "30일 동안 만족하지 않으시면 전액 환불해드립니다. 이유 묻지 않아요."
- 작은 글씨: 정확한 조건 명시

### 12. FAQ (전환 차단 해소, 6~8개)

질문 예시:
- "비전공자인데 따라갈 수 있나요?"
- "강의 시간은 얼마나 되나요?"
- "수강 기간 제한이 있나요?"
- "환불은 어떻게 받나요?"
- "결제 후 바로 시청 가능한가요?"
- "추가 비용이 발생하나요?"
- "기업/단체 수강 가능한가요?"

### 13. 강력한 마지막 CTA (Closer)

**구성**:
- 강조 배경 (어두운 배경 + 강조 컬러 텍스트)
- 헤드라인: "지금 결정하지 않으면..."
- 한정 요소:
  - "이번 기수 마감까지 [N]일 [N]시간"
  - "남은 자리: [N]/200"
- 큰 CTA 버튼: "지금 신청"
- 버튼 아래: 환불 보장 한 번 더 안내

### 14. 푸터

- 사업자 정보 (간소)
- 약관 / 개인정보 / 환불 정책 링크
- 문의 연락처
- "포트폴리오용 샘플 작업" 작게
